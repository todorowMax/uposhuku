## 5. Коротка картка по кліку на маркер

| # | Питання | Варіанти | Відповідь |
| --- | --- | --- | --- |
| 5.1 | Куди «росте» картка з маркера? | Поруч із маркером, у вільний бік · у фіксоване місце (ліворуч знизу) | Зроблено: поруч із маркером (праворуч, якщо є місце, інакше ліворуч) і їде разом з ним; на телефоні — шторка знизу |
| 5.2 | Що робить маркер під час анімації? | Лишається · фото «перетікає» в картку · підсвічується | Зроблено: фото плавно більшає й отримує тепле кільце |
| 5.3 | Зміст короткої картки | Фото, ім'я, спеціалізація, 3–5 тегів, 1–2 прев'ю проєктів, ціна «від», місто, онлайн — що беремо | Зроблено: фото, ім'я, спеціалізація, місто; стаж на платформі, замовлень, рейтинг. Тегів і проєктів поки немає |
| 5.4 | Кнопки | «Детальніше» + «Написати» / «Запросити до запиту» | Зроблено: «Переглянути профіль» і «Запропонувати роботу» |
| 5.5 | «Детальніше» — куди? | Картка росте далі в профіль поверх карти (зі своєю адресою) · окрема сторінка |  |
| 5.6 | Закриття й перемикання | Клік поза карткою, Esc, хрестик; клік по іншому маркеру перемикає картку без закриття? |  |
| 5.7 | Клік по групі (ромбу) | Наближення, як зараз · список людей групи в картці | Зроблено: група без підкладки — портрети впритул, маленькі обличчя й крапки довкола, число людей; клік наближає |
| 5.8 | Клік по запиту (кружечку) | Картка запиту з кнопкою «Відгукнутися» · неклікабельний |  |

## 6. Сторінка профілю та її заповнення

| # | Питання | Варіанти | Відповідь |
| --- | --- | --- | --- |
| 6.1 | Структура профілю | Шапка (фото, ім'я, місто, спеціалізація, теги) → проєкти → опис → відгуки; що ще і в якому порядку || Прев'ю: фото, ім'я, спеціальність, місто → цифри → «Про себе» (3 рядки) → роботи (стрічка) → теги. Відгуки — коли з'являться угоди |
| 6.2 | Відкриття проєкту | Модалка зі скріншотами · окрема сторінка · одразу посилання на живий продукт |  |
| 6.3 | Редагування | Прямо на сторінці профілю · окрема сторінка налаштувань || Прев'ю: редактор на весь екран з живим переглядом; з картки на карті — «Редагувати профіль» |
| 6.4 | Перший вхід виконавця | Покроковий майстер (фото → місто → теги → проєкт) · одна форма || Прев'ю: не майстер, а одна форма з трьома блоками й чеклістом «заповнено» |
| 6.5 | Без чого людина не з'являється на карті? | Фото, місто, теги, хоча б 1 проєкт — що обов'язкове || Прев'ю: фото, ім'я, місто, спеціальність, від двох тегів; робота не обов'язкова, але підтверджує теги |
| 6.6 | Фото профілю | Кроп у браузері (круглий) · без кропу; фото з Google за замовчуванням? || Прев'ю: кадр по центру в коло, стиснення в браузері, HEIC читається; ручного кропу немає. Фото з Google не беремо |
| 6.7 | Додавання проєкту | Посилання → чернетка від ШІ → правки; що ще: скріншоти вручну, роль, стек, термін || Прев'ю: назва, опис вільним текстом (з нього теги), посилання; чернетка від ШІ — ні (ШІ в MVP немає) |
| 6.8 | Вибір тегів | Пошук у словнику з групами · хмарка популярних; скільки максимум || Прев'ю: теги самі з тексту, зайвий — хрестик, сірі «+»; ліміту поки немає |
| 6.9 | Ціни в профілі | «Від N ₴» · погодинна · не показуємо |  |
| 6.10 | Контакти й соцмережі | GitHub, LinkedIn, сайт — так; телефон і Telegram — ні (спілкування лише в чаті)? |  |
| 6.11 | Бейджі | «Рання пташка», «Перевірений проєкт», «Безпечна угода» (ФОП) — які показуємо |  |
| 6.12 | Сторінка замовника | Потрібна · лише ім'я й фото в чаті |  |
