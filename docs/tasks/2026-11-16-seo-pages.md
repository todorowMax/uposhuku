## Goal

Профиль исполнителя и каталог «послуга (+ город)» отдают текст в серверном HTML без карты и MapLibre, чтобы их можно было индексировать,
когда владелец откроет выключатель. Главная получает `Organization` и `WebSite` JSON-LD без видимых изменений.

## Done criteria

- [ ] Прямой заход на `/p/<id>` отдаёт в HTML `h1` с именем, специальность, город, описание, теги, работы, отзывы (проверенные помечены); неизвестный или неопубликованный профиль даёт 404; страница не грузит MapLibre.
- [ ] Открытие профиля с карты (карточка, список) по-прежнему идёт поверх карты без перезагрузки.
- [ ] JSON-LD профиля: `ProfilePage` с `Person` (прежние поля + `knowsAbout`), `aggregateRating` только из проверенных отзывов и только если они есть.
- [ ] `/poslugy/<тег>` и `/poslugy/<тег>/<місто>`: `h1` («Розробка лендингів у Львові»), исполнители с карты, число открытых публичных запросов, медианный бюджет, соседние города и связанные теги, `BreadcrumbList` + `ItemList`; индексируется при 3 и более исполнителях, иначе `noindex, follow`; неизвестный тег или город дают 404.
- [ ] Sitemap содержит индексируемые страницы каталога и профили (только id и слаги, ограниченные запросы).
- [ ] На `/` есть `Organization` и `WebSite` JSON-LD, видимых изменений нет.
- [ ] `npm run lint:ci`, `npm run typecheck`, `npm test` зелёные; каждый новый тест падает без своего изменения.
- [ ] `npx next build`: новые маршруты не тянут MapLibre, first-load JS записан ниже.
- [ ] `docs/features/seo.md` и строка в карте фич `AGENTS.md`.
