# Бриф B: безопасная угода за флагом, без выдуманных данных

Задача: [../2026-11-03-prelaunch-ux-review.md](../2026-11-03-prelaunch-ux-review.md), пакет B (C-1, C-3, L-8, B-22).

## Сейчас

- `SAFE_DEAL_ENABLED = false` (`lib/legal/config.ts:40`) читается только в `lib/legal/offer.ts` и `lib/legal/terms.ts`.
- `components/deals/deal-tab.tsx` и `components/chat/direct-deals.tsx` показывают выбор «Безпечна угода · Рекомендуємо» /
  «Прямий переказ», блок «Monobank · тестовий режим», «Заморозити … (тест)», «Імітувати відмову банку».
- ФОП-статус выдуман: `lib/deals/fop.ts` (`isFop` = хеш id), используется в `deal-tab.tsx`, `direct-deals.tsx`,
  `app/api/deals/route.ts`, `app/api/conversations/[id]/deals/route.ts`.
- Прямой перевод показывает выдуманный QR и выдуманный счёт `UA•• … {last4}` (`deal-tab.tsx`, `QrBlock`, ~стр. 895–960),
  текст «Тестовий QR…».
- `app/api/deals/route.ts:41` по умолчанию ставит `method = "safe"`; `app/api/deals/[id]/route.ts:61` принимает `simulate`.
- `lib/legal/links.ts:5` даёт ссылку «Оферта для виконавців» (`/offer/safe-deal`) в списке документов.

## Сделать

1. Флаг — одна константа на всё приложение. Перенести `SAFE_DEAL_ENABLED` в `lib/deals/types.ts` (или `lib/deals/flags.ts`),
   `lib/legal/config.ts` реэкспортирует или импортирует её; не два источника.
2. **API.** При выключенном флаге: создание угоды с `method: "safe"` → `problem(409, "Безпечна угода ще недоступна")`;
   по умолчанию метод `direct` (`app/api/deals/route.ts`); действие `fund` и `simulate` → 409. Поле `fop` в ответах API
   не выдумывать: при выключенном флаге не вызывать `isFop`, отдавать `fop: false` (или убрать поле, если клиент переживёт —
   проверь типы).
3. **UI.** При выключенном флаге: блок выбора метода (`fieldset.deal-methods`) не показывать, метод всегда `direct`; ни
   «Безпечна угода», ни «Рекомендуємо», ни «Недоступна: виконавець не ФОП», ни расчёта комиссий/«До оплати» с банком.
   То же в `direct-deals.tsx`. Код безопасной угоды не удалять — он нужен, когда флаг включат.
4. **Прямой перевод без выдумок.** Убрать фейковый QR и фейковый номер счёта. Вместо них: получатель (имя), сумма,
   назначение («Оплата за роботу, угода N») и текст: «Реквізити для переказу виконавець надсилає в чаті. Платформа не
   отримує ці гроші й не повертає їх.» Кнопку «Я оплатив» (claim_paid) оставить. Функции `qrCells`/`hashCode`, если станут
   не нужны, удалить (`npm run deadcode`).
5. **Документы.** Ссылку на `/offer/safe-deal` в `lib/legal/links.ts` показывать только при включённом флаге. Саму
   страницу `app/offer/safe-deal` не трогать: её читает банк.
6. **Тесты.** Обновить те, что ломаются (`tests/unit/deals.test.ts`, `legal.test.ts`). Добавить: создание safe-угоды при
   выключенном флаге → ошибка (на уровне функции/репозитория, если роут не тестируется в проекте).
