## Что в порядке (проверено)

- `lang="uk"` на главной и на 404 (`<html lang="uk">`), viewport и `theme-color: #03090d` корректны.
- Иконки: `/favicon.ico` 200 `image/vnd.microsoft.icon`, `/icon.svg` 200, `/apple-icon.png` 200 (`image/png`).
- Юр. страницы живые, 200, у каждой свои title/description: `/legal/terms`, `/legal/privacy`, `/offer`, `/offer/safe-deal`, `/contacts`. Оператор виден (ФОП, РНОКПП, адрес), `hello@findlyfy.com` указан и совпадает с `CONTACT_EMAIL` и `MAIL_FROM` в `wrangler.jsonc`. Дата редакции "17 жовтня 2026".
- `/legal/terms`: оператор и почта в первом абзаце; в `/offer`, `/contacts` IBAN и телефона нет (кроме L-8).
- Баннер согласия (`components/legal/consent-banner.tsx`): появляется через 3 с после готовности карты (или 9 с без WebGL), есть "Добре" и "Не треба" равной видимости, учитывает Global Privacy Control, ссылка на политику. В браузере не запускал.
- `www.findlyfy.com` отвечает `HTTP/2 200` (без редиректа на apex: две копии одного сайта, см. не проверено).
- Ошибки: `app/error.tsx` и `app/global-error.tsx` есть, оба на `ProblemPage` с `role="alert"`, кнопка повтора и "На карту", отчёт в телеметрию. Украинский текст.
- MapLibre грузится динамически: `components/maplibre/vibe-map.tsx:9` `dynamic(() => import("./maplibre-scene"), { ssr: false })`; в первом HTML серверная заставка `MapSkeleton`. `public/maplibre/*` 532 КБ.
- Шрифт: `next/font/local`, `display: "swap"`, preload в `<head>`.
- Админка: `app/admin/layout.tsx` даёт 404 не-админам и `robots noindex`.

## Замечания по коду без приоритета

- `"use client"` в 120 файлах `components/app/lib/kit`; layout группы `(map)` серверный, но монтирует ~20 клиентских компонентов подряд (`app/(map)/layout.tsx`). Реальный размер JS в первом заходе не измерял; в HTML главной подключено ~20 чанков `async`.
- `www` не редиректит на apex: канонического хоста нет, canonical на главной тоже нет (см. L-4).

## Не проверено

- Реальный профиль `/p/<id>`: id не нашёл (список грузится клиентом через API; `/api/performers` -> 404, других эндпоинтов не угадывал). Title, canonical, JSON-LD, `index/noindex` для живого профиля не видел.
- Как выглядит 404 после JS в браузере (в HTML ответа текста нет), как выглядит превью в Telegram/Viber (выводы L-3 только по HTML), видимость атрибуции OSM на карте, поведение баннера согласия, клавиатура и 375 px (браузер запрещён).
- Размер и время загрузки первого JS, LCP, реальные заголовки `/_next/static/*` (кэш), работа WebGL.
- Почтовая часть: приходит ли письмо с `hello@findlyfy.com` (SPF/DKIM/DMARC), работает ли Email Routing на этот адрес.
- Cloudflare-настройки зоны (Always HTTPS, HSTS, redirect www -> apex, правила кэша): видел только результат в ответах.
- Развёрнутая версия vs последний коммит: по title/тексту совпадает, но хеш билда и дату деплоя узнать без wrangler/Cloudflare нельзя.
