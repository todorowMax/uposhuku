## Goal

У запроса появляется адрес `/zapyt/<id>`: человек из Telegram-канала видит текст запроса без входа и без контактов автора, а
кнопка «Відгукнутися» ведёт его по существующему пути (вход, профиль исполнителя, запрос в ленте). Заодно композер перестаёт
обещать вложения, которые никуда не загружаются, а индексацией и адресом сайта управляет одна переменная окружения (индексация
остаётся закрытой).

## Решения в ходе работы

- Публичной считается страница запроса, у которого стоит `channel_opt_in` (флаг «в канал», по умолчанию включён): отдельного флага «публічний» нет, S-4 предлагает переименовать галочку. Новая миграция не нужна. (why: поручение владельца «только запросы, которые автор разрешил показать в канале»)
- Страница живёт в `app/zapyt/[id]`, то есть вне группы `(map)`: корневой layout даёт только шрифт, телеметрию и баннер согласия, карта и MapLibre не грузятся. Как у `/contacts` и `/legal/*`.
- Кнопка «Відгукнутися» всегда ссылка на `/?open=request:<id>`; решает остров на клиенте (сессия и профиль уже есть в сторах), но сама логика входа остаётся в `deep-link-sync`. Вторую панель входа на странице не строю. (why: поручение «reuse, do not build a second auth path»)
- Корневой `generateMetadata` вызывает `connection()`, чтобы `SITE_URL` и `SEO_INDEXING` читались во время запроса, а не при сборке (воркерные переменные на сборке неизвестны, canonical главной получил бы `http://localhost:3031`). Цена: `/` и `/_not-found` по таблице маршрутов `next build` теперь `ƒ` (рендерятся на каждый запрос). Страница главной это один `h1`, остальное клиентское. (why: адрес сайта по среде был целью S-1)
- `X-Robots-Tag` в воркере не ставится, когда индекс открыт: иначе он перекрыл бы `noindex` закрытых запросов. (why: заголовок сильнее meta)
- Письма: в `lib/server/mail.ts` нет ссылок на запросы чужих людей (`EmailEvent` знает `message`, `offer`, `deal`; `offers:<id>` открывает собственные пропозиції автора). Менять нечего.

## Вопросы владельцу

Не блокируют работу, в коде принято значение по умолчанию.

1. **Согласие автора.** Галочка «в канал» стояла по умолчанию и значила «Telegram-канал, без контактов». Теперь она же откроет страницу на сайте без входа, для всех старых и новых запросов с галочкой. Принято: да, как в поручении. Но текст чипа в композере («У Telegram-каналі» / «Не в каналі») и подсказка про это не говорят. Предлагаю переименовать в «Публічний запит» с подсказкой «Покажемо запит у каналі й на сторінці сайту без ваших контактів». Не сделано без решения: это юридический текст согласия (LANG-4, copy owner-approved).
2. **`stripContacts` не идеален.** Он вырезает телефоны, почту, `@ник`, ссылки. Не вырезает имя, адрес, «пишіть у Вайбер» без номера. Принято: показываем текст после `stripContacts` как есть. Если нужна ручная модерация перед публикацией на сайте, это отдельная задача.
3. **Срок жизни закрытой страницы.** S-4: «30 дней, потом 410». Принято: закрытый запрос показывает «Виконавця знайдено» без ограничения срока, `noindex`; 410 и «схожі запити» (S-3) не делаю. Нужен срок или остаётся так?
4. **Экран «Редагувати запит»** (`components/requests/edit-request-screen.tsx`) тоже содержит кнопку «Додати файл» и заголовок «Файли», и тоже ничего не загружает. Поручение называет только композер, поэтому экран не тронут. Предлагаю убрать там то же самое отдельным небольшим пунктом.
5. **Автор открывает свою страницу.** Принято: автор видит свой запрос всегда (даже без галочки и закрытый) с пометкой, что страница видна только ему, и вместо «Відгукнутися» получает ссылку «Переглянути пропозиції» (`/?open=offers:<id>`).
