## Decisions

- Порядок пунктов и по коммиту на пункт, каждый откатывается отдельно (why: задание).
- `route()` возвращает функцию с запросом по умолчанию и необязательным контекстом (why: существующие тесты зовут `GET()` без аргументов, их менять не нужно).
- Для `performer:<id>` не открываю карточку на карте: выбранный маркер живёт в локальном состоянии `maplibre-scene.tsx` (3000 строк, пакет K-3), общего стора нет. Вместо этого то же действие, что у кнопки «Запропонувати роботу»: есть открытый запрос — разговор с намерением «угода», нет — подсказка в поле запроса с именем (имя берётся из `/api/performers/:id`). Стор выбранного маркера стоит завести при разборе K-3.
- `globals.css` режется только по смежным кускам, не по префиксам (why: каскад зависит от порядка, перестановка файлов поменяла бы результат, а доказать равенство можно только при сохранении порядка). Файлы названы по разделам: `inbox.css` (весь мессенджер, там же `dm-*`) и т.д.
- Stylelint: `app/styles/*.css` приравнены к файлу токенов по сырым цветам (why: в них осталось 1400+ сырых цветов из прежнего файла; замена на токены отдельная работа). Потолок Stylelint понижен 5 до 4, ESLint 436 до 414 (храповик сам).
- Токены перенесены в `app/styles/tokens.css`; строки про это в `AGENTS.md` и `DESIGN.md` исправлены.

## Lessons (candidates)

- Хук-ограничитель worktree отказывает в командах, где `git` и другие команды склеены `;`/`&&`, и в длинных heredoc: гонять git отдельным вызовом, скрипты писать файлом.
- Ratchet при коммите сам снижает потолки и включает правку `package.json` в тот же коммит: смотреть `git status` после коммита.
- `next build` пишет `route-bundle-stats.json` в `.next/diagnostics/`; ключ маршрута для перехваченных маршрутов `/(.)p/[id]`.
