## Goal

Лента переписки перестаёт быть журналом: даты, события сделок с кликабельным номером, отдельная карточка решения модератора. Список переписок получает аватар, время и осмысленное превью, а тупиковые состояния (собеседник удалил аккаунт, слишком длинный текст, ошибка загрузки, пустой фильтр) получают свои тексты.

## Done criteria

- [x] Лента делится по дням («Сьогодні», «Вчора», «12 листопада») по локальной дате зрителя.
- [x] Событие сделки это строка слева с иконкой и чипом с номером, чип открывает экран сделки; подряд идущие события одной сделки сворачиваются в «N подій за угодою #X» (последнее видно, раскрытие по клику); решение модератора это карточка «Рішення модератора»; короткие не сделочные события остаются таблеткой. Группировка в чистой функции в `lib/chat/` с тестами.
- [x] Заказчик без имени показан названием запроса, а не «Замовник / замовник»; везде слово «угода».
- [x] Строка списка: аватар (фото или инициалы), время последнего сообщения, превью последнего сообщения человека; запросов к базе не больше, чем раньше по порядку (один сгруппированный запрос).
- [x] Лента `role="log"`, начальная история не зачитывается, нижняя прокрутка только если человек внизу, иначе плашка «Нові повідомлення».
- [x] Собеседник удалил аккаунт: поле заменено текстом; счётчик у лимита 4000; ошибка списка с «Спробувати ще раз»; пустой фильтр с текстом.
- [x] `lib/requests/chat.ts` удалён.
