## Not verified

- Реальный Telegram: `deleteMessage` проверен только на подмене `fetch` в тестах. Как отвечает настоящий канал (права бота на удаление, «message can\'t be deleted» для старых сообщений, точный текст «message to delete not found»), не проверено.
- Пост старше 48 часов Telegram может не дать удалить: тогда строка остаётся с `error`, шаг повторяет попытку каждый tick (раз в 5 минут, в журнал пишется каждый раз). Политика для этого случая не выбрана.
- Пункт 4: имя исполнителя длиннее примерно 22 знаков на 375 px не поместится в две строки placeholder (полный текст есть в sr-only label и в строке под кнопкой карточки на десктопе).
