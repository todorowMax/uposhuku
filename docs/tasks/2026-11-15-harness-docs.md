## Lessons (candidates)

- Worktree, созданный из старого коммита, надо сначала догнать до `development`; иначе документы, на которые ссылается бриф, отсутствуют.
- Перенос текста между файлами делать извлечением строк (`sed -n`), а не перепечаткой: так смысл не меняется, и сверку фактов можно сделать скриптом.
- Число, которое считает команда, в `AGENTS.md` устаревает за неделю (GSAP 13 против 9, бюджет, потолки линтера): писать команду, не число.
- Список в документе («прапорці функцій») тоже дрейфует: ссылаться на константу в коде (`FEATURES`), а не дублировать перечень.
