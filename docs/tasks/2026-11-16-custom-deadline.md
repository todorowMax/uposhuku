## Goal

В окне «Термін» композера можно указать свою дату вместо одной из пяти заготовок. Дата хранится рядом с прежним бакетом срока, а все фильтры, ранжирование и уведомления продолжают работать по бакету.

## Done criteria

- [x] В окне «Термін» есть шестой вариант «Вказати дату» с полем даты (min сегодня, max сегодня + 365, по умолчанию + 14 дней) и кнопкой «Готово»; чип показывает «До 25 листопада».
- [x] Колонка `requests.deadline_date` (миграция 0028); сервер выводит бакет из числа оставшихся дней (по Europe/Kyiv) один раз при сохранении.
- [x] `parseDraft` принимает `deadlineDate`, отвергает неверные, прошедшие и дальше 365 дней; без поля поведение прежнее.
- [x] Правка запроса (PATCH) умеет менять и убирать дату; неизменённая прошедшая дата не блокирует правку.
- [x] `PublishedRequest`, `FeedItem`, `MapRequest`, `PublicRequest` несут `deadlineDate`; везде, где показывался бакет, показывается «До …».
- [x] Пост в канале и `syncEditedPosts` используют дату; тест рядом с тестами правки постов.
- [x] Новые тесты падают без изменения; `lint:ci`, `typecheck`, `test`, `deadcode` зелёные.

## Decisions

- Бакет `deadline` остаётся и является снимком на момент сохранения; со временем не пересчитывается (why: фильтры «Терміново», ранг и сопоставление читают бакет, а пересчёт по часам потребовал бы tick-шага и сломал бы кэш ленты) -> docs/features/requests.md
- Дата трактуется как календарная дата в Europe/Kyiv, без UTC-сдвигов (why: «до 25 листопада» для украинского пользователя не должно сдвигаться на день).
- `FeedItem.deadline` остаётся подписью бакета (по ней работает фильтр «Терміново»); к нему добавляется `deadlineDate`, а текст для показа собирает общий форматтер (why: не трогать фильтры).
- Неизменённая дата при правке принимается даже если уже прошла, бакет при этом сохраняется прежний (why: иначе нельзя поправить текст запроса после срока).

## Lessons (candidates)

- `FeedItem.deadline` была подписью, а не ключом, и по ней работает фильтр «Терміново»: перед заменой подписи на «До …» надо проверить, кто сравнивает строку.
- `Intl` с `Europe/Kyiv` в Node 24 работает; на Workers должно быть так же, но на dev не проверено.
