## Goal

У чата появляется состояние «непрочитано»: человек видит в списке, в какой переписке ему написали, и число таких переписок на кнопке «Повідомлення». Сейчас бейдж считает переписки, где пользователь исполнитель, и у исполнителя показывает постоянную цифру.

## Падение без изменения

Каждое изменение сделано правкой кода, прогон двух файлов тестов, откат из копии. Все падают, кроме двух первых попыток, которые были неверными мутациями и повторены.

| Правка | Упавшие тесты |
| --- | --- |
| считать и свои сообщения (убрано условие стороны) | «рахує лише текстові…», «власні…», «мітка однієї сторони…», «учасник скидає…» |
| считать служебные как текст | «звичайний службовий рядок…» |
| `unreadDeal` без `needsMe` | «звичайний службовий рядок…», «угода чекає на мене…» |
| убрана стеля 99 | «лічильник має стелю 99» |
| отметка не записывается | «угода чекає на мене…», «мітка однієї сторони…», «учасник скидає…» |
| отметка может идти назад (убран `or(isNull, lt)`) | «мітка однієї сторони… не йде назад» (после усиления теста; первая версия теста эту правку пропускала) |
| маршрут без проверки доступа | «без входу 401, чужому 404…» (первая правка меняла не то, повторена) |
| убран `rateLimited` | «ліміт частоти…» |
| подпись без окончаний | «правильне закінчення…» |
| бейдж без `needsMe` | «рахує розмови, а не повідомлення…» |

## Decisions

- Признак «непрочитано» хранится отметкой времени на сторону, а не флагом на сообщение (why: две колонки решают и список, и бейдж, без таблицы на каждое сообщение; решение принято в ревью) -> stays here.
- Сообщение считается прочитанным, если его `created_at` не больше отметки; сообщение в ту же миллисекунду, что и отметка, считается прочитанным (why: граничный случай, следующая отметка при новом сообщении его всё равно поймает) -> stays here.
- Отметка при чтении только растёт (`max` с прежней) (why: часы разных изолятов Workers могут разойтись на миллисекунды) -> stays here.
- Бейдж и подпись кнопки считают переписки, где есть непрочитанное или нужно моё действие; пилюля в строке показывает только число текстовых сообщений (why: так записано в решении владельца; событие сделки жирным именем и пометкой «чекає»/пилюлей без числа) -> stays here.

## Lessons (candidates)

- Первая версия теста «мітка не йде назад» проходила и без защиты: отметка в нём всё равно оставляла то же число непрочитанных. Мутацию нужно прогонять до того, как считать тест готовым (DONE-4).
- В `app/globals.css` классы без слоя перебивают утилиты Tailwind: `font-bold` не победил бы `.inbox-name { font-weight }`. Состояние строки задаётся атрибутом и правилом рядом с классом.

## Not verified

- Миграция не применялась к `development` и `production` (удалённые миграции запрещены в задаче). Заполнение `updated_at` проверено на копии таблицы в SQLite и на пустой локальной базе, но не на данных реального dev.
- Номер миграции `0026`: другая сессия может создать свою с тем же номером, тогда при слиянии нужно перенумеровать (файл, `meta/_journal.json`, снимок).
- Строка списка с `unreadDeal` и без текстовых сообщений (угода ждёт меня, свежая служебная строка) проверена только тестами репозитория, в браузере не смотрели; пилюли с числом у неё нет, видны жирное имя и метка угоды.
- Второй пользователь на `perf.localhost:3031` в браузере не открылся: карта висела на «підвантажується» (HMR-сокет этого домена падал), поэтому получатель смотрел на `localhost:3031`, а отправитель слал сообщения тем же API с отдельной сессией. Вид интерфейса для получателя проверен полностью, вид отправителя при отправке из UI не перепроверялся.
- Realtime-сокет локально не работает (нет воркера), поэтому событие `message` самому себе после отметки и обновление списка в других вкладках не проверялись; список обновляется оптимистично и опросом.
- Telegram и почту не трогали, как и сказано в задаче; чтение экранным диктором не проверяли (только `aria-label` и скрытый текст «Непрочитаних:» в пилюле по дереву доступности).
- Окно длиннее 99 непрочитанных: пилюля покажет «99» без плюса.
- Сообщение, созданное в ту же миллисекунду, что и отметка, считается прочитанным.
