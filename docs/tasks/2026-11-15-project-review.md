### Как переделать ленту (C-6)

1. Разделители дней: «Сьогодні», «Вчора», «12 листопада».
2. Событие сделки это строка слева с иконкой и чипом `#E571`, который открывает экран сделки. Таблетка остаётся
   только для однострочных событий.
3. Подряд идущие события одной сделки сворачиваются: «5 подій за угодою #76B5», раскрытие по тапу. Последнее видно.
4. Решение модератора это отдельная карточка: заголовок «Рішення модератора», текст, сумма. Это самое важное в
   переписке, а сейчас оно выглядит как фон.
5. Начало переписки из отклика: строка-контекст «Запит: Лендинг для кав'ярні» (в старом плане это A7, не сделано).

Порядок работ по чату: сначала баги (пакет A), потом непрочитанное (C-5), потом лента (C-6, C-7, C-8).

## Lessons (candidates)

- Ключ дедупликации уведомления должен содержать получателя. Ключ на событие без получателя глушит ответ второй
  стороны.
- Курсор «после моего последнего» нельзя двигать по собственной записи: чужая запись с меньшим временем теряется.
- Сводка «по первой найденной записи» ломается, когда на пару появляется вторая сделка. Сводку считать по всем.
- Для проверки в две роли на локальном сервере второй пользователь открывается на `<имя>.localhost`.
- Во вкладке с живым входом, которой в это время пользуется человек, не отправлять связку «клик, ввод, Enter» одним пакетом: перед каждым кликом новый снимок экрана, а проверки со сменой данных делать на отдельном тестовом аккаунте.
