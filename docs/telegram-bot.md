# Telegram-бот Findlyfy: как включить

Код бота готов и покрыт тестами (прив'язка акаунта, сповіщення, канал запитів, вебхук). Не хватает только самого бота в Telegram и секретов. Бот приватный: пишет только тому, кто подключил его на сайте, в группах молчит. Сообщения чата и тексты запросов в уведомления не попадают целиком: только имя, короткая цитата и кнопка «Відкрити».

## Что делает владелец (10 минут)

1. В Telegram открыть **@BotFather**, команда `/newbot`.
   - Название: `Findlyfy (тест)` для dev, `Findlyfy` для прода. Его видят люди.
   - Username на `_bot`: например `findlyfy_dev_bot` и `findlyfy_bot`.
2. BotFather выдаст токен вида `123456:ABC…`. **В чат и в git его не вставлять.** Положить в секреты воркера (команда спросит значение, вставить токен и Enter):

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN --env development
```

3. Тоже локально, чтобы скрипт настройки мог говорить с Telegram: добавить строку `TELEGRAM_BOT_TOKEN=<токен>` в `.dev.vars` (файл в git не попадает).
4. Написать мне username бота (это не секрет) и, если нужен канал запросов, шаги из раздела «Канал» ниже. Остальное делаю я: секрет вебхука, `TELEGRAM_BOT_USERNAME`, деплой, вебхук и проверку.

## Что делаю я после этого

- Секрет вебхука (случайный, 32 байта) в `wrangler secret` и в `.dev.vars`, без вывода в чат.
- `TELEGRAM_BOT_USERNAME` в `wrangler.jsonc` для окружения.
- `npm run cf:build` и `npm run cf:deploy:development`.
- `npm run tg:setup -- --url https://dev.findlyfy.com`: вебхук, команды (`/start`, `/settings`, `/stop`, `/help`), описание бота.
- Проверка: `npm run tg:setup -- --info` показывает вебхук без ошибок доставки; сквозной сценарий: «Підключити Telegram» на сайте, `/start` в боте, тестовое сообщение в чате, уведомление приходит, `/stop` отключает.

## Прод

Те же шаги с `--env production`, вторым ботом (в Telegram вебхук у бота один, а адреса dev и прод разные). Делаем после проверки на dev. `TELEGRAM_BOT_USERNAME` для прода записывается в блок `production` в `wrangler.jsonc`.

## Канал запросов (по желанию)

1. Создать канал в Telegram: тестовый приватный на dev, публичный на проде.
2. Добавить бота администратором с правами «Публиковать сообщения» и «Редактировать сообщения».
3. id канала (число `-100…`) появится в журнале воркера как событие `telegram_chat_member`; я возьму его оттуда и пропишу в `TELEGRAM_CHANNEL_ID`.
4. `CHANNEL_ENABLED=1`. Запрос попадает в канал через 20 минут после публикации (`CHANNEL_DELAY_MIN`), без контактов и ссылок, с кнопкой «Подивитися». Пока канал выключен, ничего не публикуется.

## Что решаем про приватность

- Подключение добровольное, по одноразовой ссылке с токеном, срок жизни ограниченный.
- Если Telegram-чат уже привязан к другому аккаунту, перепривязка должна требовать подтверждения: это исправляется в итерации L6 (сейчас привязка по чужой ссылке молча заменяет старую).
- `/stop` отключает сообщения, блокировка бота человеком тоже отключает.
- Текст сообщений чата в Telegram не уходит: только имя собеседника и кнопка.
- В политике конфиденциальности Telegram указан получателем данных.

## Что может пойти не так

| Симптом | Причина |
| --- | --- |
| Кнопка «Підключити Telegram» неактивна, написано «Скоро» | Пустой `TELEGRAM_BOT_USERNAME` |
| `/start` ничего не отвечает | Неверный вебхук или секрет; смотреть `--info` и журнал воркера |
| Уведомления не приходят | Человек онлайн на сайте (пишем только офлайн), либо выключено в настройках, либо заблокировал бота |
| Бот пишет в группе | Не должен: в группах он молчит, проверить тип чата |
