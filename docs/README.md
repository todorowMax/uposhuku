# Документи проєкту

Індекс того, що лежить у `docs/`. Правила кодингу: [AGENTS.md](../AGENTS.md), візуальні правила: [DESIGN.md](../DESIGN.md), що це за продукт: [PRODUCT.md](../PRODUCT.md). Статус тут один із: **актуально** (за цим працюємо), **у роботі**, **довідка** (джерело фактів, не план), **архів** (історія, код пішов далі). Статус задач веде лише [tasks/README.md](tasks/README.md).

## Фічі

Як працює кожна фіча (чат, запити, угоди й оплата, згоди, видалення акаунта, телефон, Telegram, захист, прапорці): [features/README.md](features/README.md).

## Задачі

Кожна задача: документ із метою, пунктами, доказами й підсумком, поруч папка з брифами й скриншотами. Єдиний індекс задач і їхніх статусів: [tasks/README.md](tasks/README.md). Тут задачі не перелічуємо.
