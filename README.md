# Vibe Map (uposhuku)

Карта виконавців і запитів в Україні: людина описує, що потрібно створити,
і бачить, хто поруч уже робив схоже. Реальні проєкти, реальні люди, з
точністю до міста, а не адреси.

Зараз зроблено глобус, поле запиту над ним і візуальний прототип маркерів.
Дані людей та запитів мокові; поле запиту поки нічого не надсилає.

## Стек

Той самий, що в mealcart: Next.js 15 (App Router), React 19, TypeScript
strict, Tailwind v4, OpenNext на Cloudflare Workers. Глобус:
[react-globe.gl](https://github.com/vasturiano/react-globe.gl) поверх three.js.

## Швидкий старт

```bash
npm install
npm run dev          # http://localhost:3031
```

Порт 3031, щоб не сваритися з mealcart на 3030.

## Команди

| Команда | Що робить |
|---|---|
| `npm run dev` | Next.js dev |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run test:unit` | Vitest: камера, розкладка маркерів, контур України |
| `npm run build` | Next-збірка |

| `npm run clouds:assets -- <файл>` | Вирізати хмари з картинки Artist |

## Як влаштований глобус

```
app/page.tsx                    сторінка: лише глобус на весь екран
components/globe/
  vibe-globe.tsx                завантажує сцену тільки в браузері
  globe-scene.tsx               сцена: шари, камера, жести
  zoom-control.tsx              «Україна — Місто» і −/+
  clouds.tsx                    хмари по краях
lib/globe/
  camera.ts                     камера карти з нахилом (чиста математика)
  materials.ts                  шейдери поверхні й плато
  html.ts                       підписи й запити
  visual-markers.ts             WebGL-портрети й групи з локального атласу
  palette.ts, region.ts         кольори й межі детальної текстури
  data/ukraine.geo.json         контур України (з Кримом)
lib/map/                        міста, демо-дані, розкладка маркерів
scripts/                        збирання текстур і хмар
public/globe/                   готові текстури й хмари
  mock-avatars.png              локальний атлас вигаданих портретів 4×4
```

**Камера.** Штатні OrbitControls globe.gl крутять камеру навколо центру
Землі, тож наблизитися можна лише до точки під камерою, а нахил виходить
тільки як побічний ефект. Тут вони вимкнені: `lib/globe/camera.ts` ставить
камеру на південь від точки фокуса, під нахилом 38° від вертикалі (у макеті
близько 55°, північ країни там відлітала вдалину). Колесо й щипок міняють
відстань до фокуса, перетягування зсуває сам фокус у межах України.
Об'єктив зсунутий униз (`setViewOffset`), тож над Україною лишається
вигин горизонту, куди ляже поле запиту.

**Поверхня.** Дві текстури в одному шейдері: уся Земля 4096×2048 і
детальна латка навколо України 80 пікселів на градус. Рельєф уже
намальований у текстурах (відмивка з висот), тому поверхня не освітлюється,
а біля горизонту тоне в серпанку кольору тла.

**Плато України.** Полігон, піднятий на 25 км. Верх малюється тією самою
детальною текстурою, вибіленою в колір плато: річки й водосховища
просвічують. Зблизька плато нижчає: будується один раз, а висоту міняє
масштаб від центру Землі.

**Маркери.** Виконавці показані компактними фотоаватарками трьох розмірів.
У демо розмір відповідає моковому рівню платного розміщення, а не якості
роботи. Аватарки й групи — WebGL-спрайти на самій планеті: під час руху
камери вони переміщуються разом із поверхнею. Київ, Львів та інші міста
з багатьма людьми мають скляний ромб із кількістю та двома фото-прев’ю.
Натискання на ромб наближає карту й показує учасників; він стає кнопкою ×
для згортання групи. Це також можна зробити великою кнопкою в картці міста
або клавішею Escape. Натискання на аватарку відкриває демопрофіль.
Запити залишаються окремими круглими точками. Позиції
виконавців декоративно розкладені біля міста лише на суходолі, без
справжніх адрес. Портрети вигадані й зберігаються локально.
Промпт і спосіб підготовки мокового атласу — у `design/avatar-mock-asset.md`.

## Дані й ліцензії

- Висоти й глибини: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)
  (Terrarium), відкриті дані.
- Кордони, річки, озера: [Natural Earth](https://www.naturalearthdata.com/),
  суспільне надбання.
- **Кордони беруться з `ne_10m_admin_0_countries_ukr`**, версії з погляду
  України. У звичайних `ne_*_admin_0_countries` Крим віднесено до Росії.
  Тест `tests/unit/map-data.test.ts` падає, якщо контур перемалюють не з того
  файлу.
- Каховське водосховище з озер прибране: його спущено після підриву греблі
  у 2023 році.
- Хмари: генерація в Artist. У `assets/artist/clouds-sides.jpg` поки лежить
  прев'ю 1280×720; оригінал підміняється тією самою командою
  `npm run clouds:assets -- <файл>`.

## Що свідомо спрощено

- Рівень «Місто» ще не місто: найближче камера бачить близько 250 км, далі
  текстура розмивається. Для справжнього міста потрібні тайли
  (`globeTileEngineUrl` у globe.gl).
- Дані демонстраційні (`lib/map/demo.ts`), бекенду, справжніх оплат і
  профілів ще немає.
- Деплой на Cloudflare налаштований мінімально: без акаунта, доменів і
  бази, лише щоб `cf:build` і `cf:preview` працювали.
